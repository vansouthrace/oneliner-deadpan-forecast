A make.fun entry for the "Deadpan Forecasts for Cities That Do Not Exist" bounty: one absurd but believable weather line for an invented city, in at most 160 characters.

> Widdershins: 12 degrees, winds from the north at 40 miles an hour, and one cloud that has been following Mrs. Aldous since 1987.

## How to run

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` and prints the character count (128).

## Why this line

It keeps the dry broadcast tone all the way through — temperature, wind speed, direction — and then slips in a single impossible detail delivered as routine fact: one cloud, one named resident, stalking her since 1987. Against a field of short absurdist flashes, this one earns its believability with concrete numbers first and lets the joke land quietly. The deadpan is the joke: the forecaster reports a haunting the way they would report drizzle.
